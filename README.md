# BloodLink

**Every Drop Connects a Life.**

BloodLink is a homepage prototype for a platform that brings voluntary blood donors, hospitals and authorised blood banks closer together.

> Prototype only. All donors, requests, hospitals, statistics and registrations are sample data. Nothing is sent or stored, and nothing here is a real medical service.

## Features
- Donor finder filtered by blood group, city and availability
- Demo urgent requests with an urgency filter
- Three-step donor registration with validation (stays in the browser)
- Eligibility education and myth-vs-fact flip cards
- Interactive red-cell blood group compatibility chart
- Searchable demo hospital and blood bank directory
- Animated impact counters and donation journey
- Responsive layout with light and dark theme

## Run locally
Open `index.html` in your browser. No installation is needed.

## Tech
Plain HTML, CSS and JavaScript, with no backend, no build step and no dependencies. Font: Plus Jakarta Sans (Google Fonts).

## Project structure
- `index.html`: page structure and SVG illustrations
- `style.css`: design system and layout
- `script.js`: interactions and sample data

## Disclaimer
Eligibility information is general and does not replace professional medical screening. Blood group compatibility is simplified and not clinical advice.
